### R11 bulk 翻译静默跳过可见化（小中）
现状：`CreateBulkRequest` 无返回值，无源字幕/无路径的媒体静默跳过只写日志，用户以为提交成功。
- 服务端：`CreateBulkRequest` 返回 `BulkRequestSummary { int Created; List<BulkSkip> Skipped }`，`BulkSkip { int MediaId; string Title; string Reason }`（reason 码：`no-source`/`no-path`，前端本地化）。签名变更波及两个接口 + TranslationRequestService 包装 + TranslateController 返回 200 响应体。
- 前端：translate store 返回 summary；LibraryPage 批量翻译后 toast「已创建 N 个任务」，skipped>0 时追加 toast「M 部无源字幕已跳过」（i18n 键 `library.bulk.created` / `library.bulk.skipped` 已预置）。
- 测试：队列服务汇总统计 + 端点响应 + LibraryPage toast spec。

### R14 搜索批内并发 8（中）

- `SemaphoreSlim(8)` 有界并发处理媒体级扇出；**源内仍串行**（7 源限流按源计，媒体并发已足够摊开）。
- 每媒体管线异常隔离（一个媒体失败不断轮），history 行照记。

- 测试：并发上限不超 8、异常隔离、全部完成语义。

### R15 路径白名单 symlink 解析（小中，安全加固）
现状：`PathConversionService` 白名单纯词法前缀比对，白名单内符号链接可逃逸到目录外（LAN 单用户低危，仍应修）。
- 校验前对**请求路径与白名单根**做符号链接解析（`UnixFileMode` 家族勿用——历轮坑；用 `FileSystemInfo.ResolveLinkTarget(returnFinalTarget: true)` 或逐段 `GetLinkTargetInfo` 兜底跨平台），比对解析后的真实路径前缀。
- 跨平台注意：macOS/Linux symlink、容器内 bind mount 不受影响；Windows junction 可留 TODO 注释。
- 测试：symlink 指向白名单外 → 拒绝；symlink 留在白名单内 → 放行；无 symlink 行为不变。
