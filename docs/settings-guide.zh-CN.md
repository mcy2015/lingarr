## 1. 集成

配置 Lingarr 与媒体库管理工具的对接,是实现自动翻译的前提。

### Radarr 设置 / Sonarr 设置

| 选项 | 说明 |
|---|---|
| 地址 | Radarr/Sonarr 的 API 地址,如 `http://localhost:7878`(Radarr)、`http://localhost:8989`(Sonarr) |
| API 密钥 | 在 Radarr/Sonarr 的 设置 → 通用 → API 密钥 中复制,固定 32 字符 |
| 默认包含新导入的内容 | 开启后,新导入媒体在索引时自动纳入翻译范围,无需在媒体页手动勾选 |

- Radarr 管电影、Sonarr 管剧集;Lingarr 通过它们的 API 拉取媒体清单和文件路径。
- 「看不到媒体?请尝试启动同步任务以重新建立索引」——链接跳转到 任务 页手动触发一次同步。

### Webhook(集成页内)

在 Radarr/Sonarr 里配置 Webhook 指向 Lingarr 给出的 URL,即可在**新媒体入库时自动触发翻译**,而不必等定时索引。页面提供了逐步菜单路径指引(Settings → Connect → Connections → +)。

### 目录映射(隐藏页,集成页入口)

当 Lingarr 容器内的路径与 Radarr/Sonarr 看到的路径不一致时(比如 Docker 挂载路径不同),在此建立 **源路径 → 目标路径** 的映射规则,并指定媒体类型(电影/剧集)。Lingarr 索引媒体时会按映射把路径翻译成自己能访问的路径。

## 2. 身份验证

控制 Web 界面的访问安全,以及对外 API 的调用凭证。

| 选项 | 说明 |
|---|---|
| 启用身份验证 | 开关登录保护。**启用前必须至少创建一个用户**,否则无法开启 |
| 用户管理 | 创建/编辑/删除用户,可设置用户名与密码(密码 ≥4 字符),显示最后登录时间 |
| API 密钥 | 生成/重新生成 API Key,供外部程序调用 Lingarr REST API 时使用;请求时通过 `X-Api-Key` 请求头传入(页面附 curl 示例) |

- 多用户场景下每个成员独立账号;密码修改留空即保持原密码。
- API Key 重新生成后旧密钥立即失效。

## 3. 服务

配置翻译引擎及其调用方式,是 Lingarr 的核心配置页。

### 翻译服务列表

- **主服务**:翻译请求的首选引擎。
- **回退服务(Fallback)**:主服务失败(超时、额度耗尽、报错)时按顺序自动切换尝试,可添加多个、可排序、可移除。
- 每个服务卡片点击「配置凭据」填入 API Key 等信息。
- 支持的服务:LibreTranslate(自建,免费)、DeepL、OpenAI、Anthropic、Gemini、xAI、Mistral、DeepSeek,以及任意 OpenAI 兼容端点(本地 Ollama 等)。

### 源语言与目标语言

- 选择翻译的源语言和目标语言(可多选);发起翻译时同时使用两者。
- 语言回退:若服务不支持精确的语言代码(如 `zh-CN`),自动落到最接近的变体(如 `zh`)。

### 翻译请求(服务页内)

| 选项 | 说明 |
|---|---|
| 使用批量翻译 | 将多条字幕行合成一个批次发给 AI,提高效率与上下文利用率。**注意:带上下文的逐行翻译质量仍更优**,追求质量建议关闭 |
| 批量大小 | 单个批次包含的字幕行数 |
| 请求超时 | 单次请求最长等待时间(分钟)。本地慢速 AI 建议调大 |
| 最大翻译重试次数 | 每行/每批失败后的重试上限 |
| 重试间隔 | 首次重试前的等待秒数 |
| 重试延迟倍数 | 指数退避:每次重试后延迟按此倍数递增(如 2s → 4s → 8s) |

## 4. 字幕

控制字幕文件在翻译前后的**清理与时间轴处理**。

### 字幕处理

| 选项 | 说明 | 建议 |
|---|---|---|
| 若存在带标签的字幕则跳过翻译 | 目标语言已有「听障(HI)/强制」标签字幕时不再翻译 | 已有 HI/Forced 字幕时开启 |
| 修复重叠字幕 | 自动裁剪前一条字幕的结束时间解决重叠 | ⚠️ 对本身不同步的字幕无效,多数情况反而造成不同步,**谨慎开启** |
| 去除字幕格式 | 移除 SRT 中的斜体/粗体/颜色/位置标签,输出纯文本 | 追求纯净译稿时开启 |
| 保留换行 | 多行字幕译后保持分行,不合并为单行。AI 服务整条一次翻译;DeepL 等传统服务逐行翻译 | 保持双语排版时开启 |
| 添加翻译者信息 | 在字幕文件开头写入译者信息注释行 | 可选,标注来源 |
| 移除语言标签 | 输出文件名去掉 `.en.` 这类语言标记 | 按播放器命名习惯选择 |
| 使用字幕标签 | 在文件名后附加**自定义片段**(非标准命名规范,可能与其他应用冲突) | 除非播放器有特殊要求,否则不建议 |

### 字幕校验(字幕页内)

启用后,处理字幕文件时逐条应用规则,**任一校验失败则取消该文件的翻译**:

| 规则 | 含义 |
|---|---|
| 字幕最短显示时长(毫秒) | 单条字幕至少停留多久,防止闪跳 |
| 字幕最长显示时长(秒) | 单条字幕最多停留多久 |
| 字幕最少字符数 | 单条字幕至少几个字符 |
| 字幕最多字符数 | 单条字幕最多几个字符 |
| 字幕文件最大大小(字节) | 整个字幕文件的大小上限 |

用途:拦截异常字幕(时间轴错乱、行数畸多、文件超大),避免浪费翻译额度。

## 5. 自动化

让 Lingarr 按计划自动干活,无需人工点翻译。

| 选项 | 说明 |
|---|---|
| 媒体索引计划(电影/剧集) | Cron 表达式,控制与 Radarr/Sonarr 的同步频率(如 `0 * * * *` = 每小时)。分电影和剧集两条独立计划 |
| 自动翻译 | 总开关,开启后配合翻译计划自动翻译新入库且被包含的媒体 |
| 设置翻译计划 | 自动翻译的 Cron 触发频率 |
| 限制每次计划执行的翻译数量 | 防止单次计划翻译过多,给 API 额度/硬件减压 |
| 电影/剧集文件延迟(小时) | 新文件落盘后**至少等待多少小时**才允许翻译——给下载器留出整理、重命名的时间 |

> 页面提示:启用自动化后,还需在 服务 页配置好可用的翻译引擎。

## 6. 插件

从插件目录加载**第三方翻译服务**(C# DLL,挂载到 `PLUGINS_PATH` 目录)。

- 页面列出已加载的插件及其设置项(设置项由插件自定义)。
- 凭据不在本页配置,统一到 服务 页对插件服务商进行配置。
- 无插件时显示提示:把 DLL 放入插件目录后重启 Lingarr 即可。

## 7. 任务

查看并管理 Lingarr 的后台作业(基于 Hangfire)。

| 列 | 说明 |
|---|---|
| 任务名称 | 如媒体同步、自动翻译计划等 |
| 状态 | 运行中/等待/成功/失败 |
| 上次执行 / 下次执行 | 时间戳 |
| 操作 | 「运行」按钮手动立即触发一次 |

典型用法:改完集成配置后手动跑一次同步;调试自动化前先手动执行翻译任务看日志。

---

## 8. 日志

实时查看系统日志(WebSocket 推送,非文件)。

| 功能 | 说明 |
|---|---|
| 级别筛选 | 所有级别 / 信息 / 警告 / 错误 |
| 自动滚动 | 开启后跟随最新日志滚动,方便盯实时输出 |
| 导出 | 把当前日志导出为文本(含生成时间、总条数、堆栈跟踪) |
| 清空 | 清除当前显示的日志 |

排障入口:翻译失败、服务连不上、索引异常都能在这里找到对应记录。

## 9. 遥测

| 选项 | 说明 |
|---|---|
| 共享匿名使用统计 | 默认关闭。开启后**每 7 天最多上报一次**:Lingarr 版本、平台、报告日期,以及统计页的累计数据(翻译文件/行数/字符数,按服务、语言对、媒体类型、模型的分布) |

明确不收集:个人信息、文件名、字幕内容。安装标识为随机生成值,服务端只存哈希。

## 10. 目录映射

> 入口:集成页 → 「看不到媒体?」提示或直接访问 `/settings/mapping`。

管理「源路径 → 目标路径」映射规则(见第 1 节说明)。每条规则指定:

- **源**:Radarr/Sonarr 报告的路径前缀
- **目标**:Lingarr 容器内对应的挂载路径前缀
- **媒体类型**:电影 / 剧集

支持弹窗浏览目录选择(DirectoryModal),保存后立即生效。

## 11. 请求模板

> 入口:服务页 → 某个 AI 服务卡片 → 「打开请求设置」。仅 AI 类服务可用。

三个页签,深度定制 AI 调用行为:

### AI 请求体模板

- 自定义发送给 AI 服务商的 **JSON 请求体结构**(默认按 OpenAI/Anthropic 等格式预置)。
- 可视化构建器增删属性/数组项,支持实时预览最终 JSON。
- 占位符(如 `{model}`、`{systemPrompt}`、`{userMessage}`、`{sourceLanguage}` 等)在翻译时于**整个模板任意字段**内替换。
- 语言格式可选:代码(`en`)或英文名称(`English`)。

### 翻译提示词

| 提示词 | 作用 |
|---|---|
| 系统提示词 | 设定 AI 的行为与语气(如「你是专业字幕译者,保持口语化」) |
| 用户提示词 | 指令模板,可插入占位符;**前文/后文上下文**占位符把当前字幕前后几行一并送入,提升连贯性 |
| 带译文的结构化上下文 | 开启后上下文按 JSON 结构发送,并附带**已翻译行的译文**,帮助 AI 保持人名、术语前后一致 |

注意:批量翻译模式下用户提示词不生效,字幕批次直接作为用户消息发送。

### 校对提示词

- 对已完成翻译逐行校对时使用:系统提示词定义 AI 比对原文/译文的职责,用户提示词随每次请求携带原文行与译文行占位符。
- 校对结果在「翻译详情」页逐行查看,可采纳建议。

## 附:设置项与功能的关系速查

| 想实现… | 去哪里配 |
|---|---|
| 接入我的媒体库 | 集成 → Radarr/Sonarr 地址与 API Key |
| 新片自动翻译 | 集成 → Webhook;或 自动化 → 索引+翻译计划 |
| 换/叠加翻译引擎 | 服务 → 主服务 + 回退链 |
| 省钱省额度 | 服务 → 翻译请求(批量+重试);字幕 → 校验;自动化 → 限制数量 |
| 译文质量 | 服务 → 关批量、调提示词(请求模板);字幕 → 保留换行 |
| 字幕时间轴异常 | 字幕 → 修复重叠(谨慎);日志排查 |
| 对外脚本调用 | 身份验证 → API 密钥(`X-Api-Key` 头) |
| 深度自定义 AI 请求 | 请求模板 → 请求体 + 提示词 |
