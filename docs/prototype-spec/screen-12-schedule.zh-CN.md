# Screen 12 · 定时任务(`data-screen="schedule"`)

下钻屏。Hangfire recurring 任务一览:队列深度、cron、启停与手动触发。

- **入口**:设置 · 系统「面板」/ ⌘K「定时任务」
- **顶栏**:定时任务 · Hangfire · 6 队列 · recurring 一览 · CTA「＋ 新建任务」
- **布局**:pb-head(固定)→ 队列深度行(固定)→ 任务表卡(滚动)。

## 元素清单

### 1. 页头(`.pb-head`)

| 元素 | 内容/行为 |
|---|---|
| 「← 系统」 | 返回 settings |
| 标题块 | 「定时任务」+ mono 副行「Hangfire · 6 队列 · 并发 MAX_CONCURRENT_JOBS=2」 |
| 「查看任务队列」 | → queue |

### 2. 队列深度(`.qdepth`,6 卡 3 列)

| 数值 | 标签 |
|---|---|
| 12(accent) | translation 排队 |
| 2 | 正在执行 |
| 1 | system 排队 |
| 0 | movies / shows |
| 0 | webhook / default |
| 98.2% | 30 天任务成功率 |

### 3. 任务表(6 列)

列:任务(名称+meta job 类型)/ cron(mono)/ 上次 / 下次 / 状态 chip / 操作(90px)。

| 任务 | job · 参数 | cron | 状态 | 操作 |
|---|---|---|---|---|
| 每日补缺 | AutomatedTranslationJob · 限额 50 任务/次 | `0 4 * * *` | ✓ 开启(ok) | 触发 |
| 统计快照 | StatisticsJob | `0 3 * * *` | ✓ 开启 | 触发 |
| 媒体同步 · Sonarr | SyncShowJob · 46 剧集 | `*/30 * * * *` | ✓ 开启 | 触发 |
| 媒体同步 · Radarr | SyncMovieJob · 312 电影 | `0 */2 * * *` | ✓ 开启 | 触发 |
| 每周清理 | CleanupJob · 孤儿字幕与临时文件 | `0 2 * * 0` | ✓ 开启 | 触发 |
| 每周全库巡检(行 opacity .55) | 只检不翻 · 生成缺字幕报告 | `0 5 * * 0` | 关闭(dim) | **启用** |

「上次/下次」列格式:mono 12px(如「今 04:00 · 312s」「明 04:00」「15:30 · 8s」「周日 02:00 · 1.2s」;关闭任务为「—」)。

## 交互逻辑

1. **「启用」**(关闭行):行复活(opacity 恢复、chip → ok「✓ 开启」、按钮 → 「触发」)+ toast「已启用:任务名」。与设置 · 自动化批次的开关同源语义。
2. **「触发」**(开启行):「上次」列 → 「刚刚 · 运行中…」+ chip → busy「▸ 运行中」+ toast「已触发:任务名」;约 2.2s 后 → 「刚刚 · N.Ns」(模拟耗时)+ chip 恢复 ✓ 开启。
3. **CTA「＋ 新建任务」**(菜单):「每日补缺」/「每周全库巡检」(toast 已创建 recurring)/ 分隔线 /「自定义 cron…」→ 表单(名称 + cron 表达式,初值「0 5 * * *」mono)→ toast「已创建 名称 · cron」。(迁移时:应真正插行,与设置 · 自动化批次「＋新增批次」合并为同一能力。)

## 状态完备(迁移时补)

任务级开关(当前只有「启用」,无停用路径 —— 设置屏自动化批次有 switch,两处应统一);运行中任务的历史记录入口;失败任务呈现;队列深度与概览/队列屏计数同源联动;cron 可读化(humanize)显示。
