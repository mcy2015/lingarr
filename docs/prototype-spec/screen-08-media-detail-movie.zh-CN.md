# Screen 08 · 媒体详情 · 电影(`data-screen="media-detail-movie"`)

下钻屏。电影的当前任务 + 来源历史(无集表,与剧集详情区分的简化形态)。

- **入口**:媒体库电影行「详情」/ ⌘K「Dune」
- **顶栏**:媒体详情 · Dune: Part Two · 电影 · EN → ZH · CTA「翻译缺失 ▸」→ toast「翻译进行中 · 请求 #2418 · 38%」(已有任务在跑时的占位行为)
- **布局**:pb-head(固定)→ toolbar(固定)→ 进行中任务卡(flex 1)→ 翻译历史卡(flex 1),两卡各自滚动。手机单列。

## 交互逻辑

1. jobrow 点击 → queue-detail(按钮除外)。
2. 历史行「详情」→ queue-detail;「导入台」→ import。
3. CTA 为占位(有任务时提示进行中;迁移时:无任务才创建翻译,语义与剧集屏「翻译缺失」统一)。

## 状态完备(迁移时补)

无任务电影(进行中卡隐藏或显示「未翻译 · 开始翻译」主行动);历史多条请求的分页;失败任务的醒目入口(当前示例无失败);源轨缺失(无 EN)时的引导(去导入)。
