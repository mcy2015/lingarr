# Screen 01 · 概览(`data-screen="overview"`)

主导航第 1 屏,默认屏。回答「我的翻译管线现在什么状态」:管线全景 → KPI → 活跃任务 + 服务健康 → 动态 → 趋势。

- **入口**:侧栏「概览」/ 快捷键 `1` / 默认加载
- **顶栏**:概览 · 管线正在运行 · 数据 5 秒前更新 · CTA「⇪ 导入字幕」→ import

## 布局

纵排五区,`.cols` 区 flex:1 占满剩余高度:管线图 → KPI 行 → 双列(活跃任务 1.6fr / 服务健康 1fr)→ 最近动态卡 → 产量成本卡。

## 交互逻辑汇总

1. 管线节点与 KPI 点击 → `location.hash` 跳转对应屏(去库/队列后应带过滤参数 —— 迁移时落地为路由 query)。
2. 活跃任务行点击 → queue-detail。
3. CTA → import。
4. 数据语义:概览所有数字是派生统计(库总数/缺字幕/队列计数/服务健康/写回统计),真实实现来自统计查询 + SignalR 推送刷新(副标题「数据 5 秒前更新」)。

## 状态完备(迁移时补)

原型仅展示健康态数据。需补:无任务时活跃任务卡空态、服务全部离线时健康卡提示、趋势无数据(新装机)空态、SignalR 断连时副标题与「实时」meta 的降级显示。
